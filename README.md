# 🚗 Game Mobil 3D

Game Mobil 3D adalah proyek game berbasis web yang menghadirkan pengalaman bermain dengan visual tiga dimensi (3D). Proyek ini dibuat sebagai eksplorasi pengembangan game interaktif yang dapat dijalankan langsung melalui browser tanpa perlu menginstal aplikasi tambahan.

## 🎮 Live Demo

Mainkan game melalui tautan berikut:

**[Game Mobil 3D – Play Now](https://obiepramudia.github.io/Game_Mobil_3D/)**

## ✨ Deskripsi Proyek

Proyek ini berfokus pada pengembangan game mobil dengan tampilan 3D yang interaktif. Pengembangan dilakukan untuk mempelajari penerapan teknologi web dalam membangun pengalaman bermain yang menarik, mulai dari visualisasi objek hingga interaksi pengguna di dalam game.

## 🛠️ Teknologi

- HTML — membangun struktur halaman web.
- CSS — mengatur tampilan dan tata letak antarmuka.
- JavaScript — mengatur logika dan interaksi game.
- Teknologi grafis 3D berbasis web — untuk menampilkan objek dan lingkungan tiga dimensi.

## 🎯 Tujuan Pengembangan

- Mempelajari dasar pengembangan game berbasis web.
- Memahami penerapan objek dan visualisasi 3D.
- Mengembangkan kemampuan pemrograman JavaScript dan desain antarmuka.
- Membuat proyek interaktif sebagai bagian dari portofolio pengembangan web.

## 🚀 Cara Mengakses

1. Buka tautan [Game Mobil 3D](https://obiepramudia.github.io/Game_Mobil_3D/).
2. Tunggu hingga game selesai dimuat.
3. Ikuti petunjuk yang tersedia pada halaman game untuk mulai bermain.
